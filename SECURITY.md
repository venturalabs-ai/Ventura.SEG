# Security Policy — Ventura.SEG

## Reporting a Vulnerability

Se você descobrir uma vulnerabilidade de segurança neste projeto, por favor reporte de forma responsável.

**Não abra issues públicas** para vulnerabilidades de segurança.

Em vez disso, envie um e-mail para o mantenedor:

- **Contato**: Tec.Wemerson@outlook.com
- **Assunto**: `[SECURITY] Ventura.SEG - Descrição breve`

Inclua o máximo de detalhes possíveis:
- Descrição da vulnerabilidade
- Passos para reproduzir
- Impacto potencial
- Qualquer proof-of-concept (se seguro compartilhar)

Você receberá uma confirmação de recebimento em até 72 horas.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| releases futuros | :white_check_mark: |

## Disclosure Policy

- Vulnerabilidades serão tratadas com prioridade.
- Correções serão liberadas o mais rápido possível.
- Crédito será dado ao reporter (a menos que solicitado anonimato).

Obrigado por ajudar a manter o Ventura.SEG seguro.
