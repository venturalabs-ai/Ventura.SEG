# Código de Conduta

Este projeto adota o [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) v2.1.

## Nosso compromisso

Ambiente aberto e acolhedor para todas as pessoas, independentemente de idade, corpo, deficiência, etnia, identidade de gênero, experiência, nacionalidade, aparência, raça, religião ou orientação sexual.

## Comportamentos esperados

- Respeito e empatia
- Feedback construtivo
- Foco no que é melhor para a comunidade

## Comportamentos inaceitáveis

- Assédio, trolling, insultos
- Conteúdo sexual ou violento
- Divulgação de informações privadas de terceiros
