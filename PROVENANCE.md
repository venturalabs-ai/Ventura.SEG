# Provenance

This file records authorship, third-party references and licensing boundaries for `Ventura.SEG`.

## Ventura-authored material

The security architecture, policies, Python modules, tests and project documentation in this repository are maintained as Ventura Labs AI project material unless a file states otherwise.

## Third-party dependencies and references

This project uses open-source dependencies and external systems through their published APIs and packages, including Python packages and optional HashiCorp Vault integration. Dependency names, trademarks and external technologies do not imply affiliation or certification.

Runtime and development dependencies are declared in `requirements.txt` and `requirements-dev.txt`. The SPDX SBOM generated by CI/release workflows is the machine-readable inventory for a specific build/release.

## Security claims

Security controls reduce risk but do not constitute certification. Claims about coverage, vulnerabilities or effectiveness must be tied to reproducible tests/scans for the referenced commit or release.

## Contribution rule

Before adding copied, translated or adapted third-party material, record the upstream project, URL, version/commit when practical, license/terms, reuse type and affected files. Conceptual inspiration alone should be described as a reference rather than copied provenance.
